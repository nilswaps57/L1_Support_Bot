## Chat API

### `POST /api/v1/chat`

**Request**:
```json
{ "session_id": "uuid", "question": "What is task code BA435?" }
```

**200 — Grounded answer (SC-001, FR-014)**:
```json
{
  "answer_id": "uuid", "session_id": "uuid", "question": "What is task code BA435?",
  "answer_text": "Task code BA435 is the FLEXCUBE screen for...",
  "answer_type": "GROUNDED",
  "citations": [{
    "chunk_id": "uuid", "document_id": "uuid",
    "document_name": "FLEXCUBE User Manual v11.11",
    "page_number": 142, "section": "Chapter 5 > Task Codes > BA435",
    "task_code": "BA435", "screen_name": "Customer Account Screen",
    "menu_path": "Customer Management > Accounts", "error_code": null,
    "jira_id": null, "rca_reference": null, "source_type": "flexcube_manual",
    "relevance_score": 0.92
  }],
  "insufficient_information": false,
  "model_used": "phi3.5", "retrieval_latency_ms": 45,
  "generation_latency_ms": 1230, "total_latency_ms": 1275, "turn_order": 1
}
```

Citation source-location fields are optional. The API omits fields whose metadata is not
available; it never infers or fabricates a page number, section, task code, screen name,
error code, JIRA ID, or other source location. `chunk_id` is the source identity and must
belong to the chunks retrieved for the current question. Only chunks explicitly identified
by the grounded response as materially supporting the answer are returned.

Insufficient and ambiguous responses return `citations: []`. A citation referring to a
chunk outside the current retrieval set, a mismatched source document, or a deleted or
otherwise non-queryable document is rejected before the response is returned.

**200 — Insufficient information (SC-004, FR-017)**:
```json
{
  "answer_type": "INSUFFICIENT",
  "answer_text": "The available knowledge sources do not contain sufficient information to answer this question.",
  "citations": [], "insufficient_information": true,
  "model_used": null, "retrieval_latency_ms": 32, "generation_latency_ms": 0
}
```

**200 — Partial answer (FR-018)**:
```json
{
  "answer_type": "PARTIAL",
  "answer_text": "The knowledge base contains information about X but does not cover Y...",
  "citations": [...], "insufficient_information": false
}
```

**200 — Ambiguous question (FR-019)**:
```json
{
  "answer_type": "AMBIGUOUS",
  "answer_text": "Your question could refer to multiple FLEXCUBE entities: ...",
  "citations": [], "insufficient_information": false
}
```

**404** `SESSION_NOT_FOUND`

**503** `LLM_UNAVAILABLE` — "Answer generation is temporarily unavailable." (never fabricated answer — SC-018)

**503** `VECTOR_STORE_UNAVAILABLE`

## Feedback API

### `POST /api/v1/feedback`

**Request**:
```json
{ "session_id": "uuid", "answer_id": "uuid",
  "rating": "helpful", "comment": "Very clear." }
```

`rating` must be `helpful` or `not_helpful`. `comment` optional; max 1000 chars.
The answer ID is issued by the chat API. The server enriches feedback from the stored
answer context and ignores client-supplied question, answer, citation, or configuration
details.

**201**: `{ "feedback_id": "uuid" }`
Repeated submissions for the same answer are idempotent and return the existing feedback
identifier with `200 OK`.

**200**: `{ "status": "ok", "model": "phi3.5", "latency_ms": 45 }`
